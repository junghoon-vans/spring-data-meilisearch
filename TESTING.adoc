= Testing

== Run the tests

[source,bash]
----
./mvnw test
----

== Create integration test

For an integration test, use the test harness annotation and a configuration bound to its container:

[source,java]
----
@MeilisearchTest
@ContextConfiguration(classes = {MeilisearchTestConfiguration.class})
class MovieIntegrationTests {

    @Autowired
    MeilisearchOperations operations;

    @Test
    void instanceIsHealthy() {
        assertThat(operations.instanceOps().isHealthy()).isTrue();
    }
}
----

`@MeilisearchTest` starts a Meilisearch container for the class.
`MeilisearchTestConfiguration` registers a `MeilisearchClient` and `MeilisearchOperations` connected to that container.
The default container image is pinned to `v1.54.0` by `@MeilisearchTest`.
`SortableMeilisearchRepositoryIntegrationTests` runs against `v1.16.0`, the earliest server version exercised by the sorted-listing compatibility test; other operations have their own server-version requirements.
Give tests for different server versions distinct `@ContextConfiguration` configuration types
so Spring does not reuse a context bound to another container.
